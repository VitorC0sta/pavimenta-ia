# Prompts de retomada

Estes arquivos são handoffs manuais para iniciar uma nova sessão sem depender do histórico anterior.

## Como usar no Kiro IDE

1. Abra uma nova sessão.
2. Anexe o prompt desejado usando `#File`.
3. Peça para continuar a partir das tarefas pendentes.
4. Anexe também `#spec:dashcam-mvp` quando quiser trabalhar no fluxo Spec.

## Prompts disponíveis

- [`retomar-dashcam-mvp.md`](retomar-dashcam-mvp.md): continua a implementação e validação do MVP atual.

Atualize o prompt ao final de cada sessão relevante. Não marque validações como concluídas sem executá-las.
