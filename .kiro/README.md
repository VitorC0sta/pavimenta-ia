# Contexto do projeto no Kiro

Esta pasta concentra os artefatos usados para documentar, planejar e retomar o desenvolvimento do Pavimenta IA.

## Estrutura

- [`docs/`](docs/README.md): documentação funcional e visual, organizada por tela.
- [`specs/`](specs/README.md): especificações reconhecidas pelo fluxo Spec do Kiro.
- [`prompts/`](prompts/README.md): prompts manuais de handoff para continuar o trabalho em outra sessão.

## Uso rápido

1. Consulte a tela em `docs/screens/<tela>/README.md` antes de alterar sua interface.
2. Use `#spec:dashcam-mvp` para carregar a spec do MVP no Kiro.
3. Em uma nova sessão, anexe `prompts/retomar-dashcam-mvp.md` com `#File` e peça para executar as pendências.

> `docs/` e `prompts/` são convenções internas deste repositório. `specs/` segue a estrutura reservada do Kiro.
